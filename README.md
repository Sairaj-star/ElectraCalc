# BMI Calculator

A clean, elegant BMI (Body Mass Index) calculator that runs entirely in the browser. No backend, no database, no data stored.

## ✨ Features

- **Metric & Imperial** unit support (kg/cm and lb/ft/in)
- **Live gauge** with animated needle showing your position
- **4 BMI categories** — Underweight, Normal, Overweight, Obese
- **Healthy weight range** calculated for your height
- Fully responsive — works on mobile and desktop
- Press `Enter` to calculate instantly
